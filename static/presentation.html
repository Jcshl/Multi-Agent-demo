01项目做什么

用户一句话可能混合「查攻略」「查玩家 UID 数据」或纯闲聊。单一对话机器人容易串意图或编造数据库字段。 本项目用编排器先判定意图，再交给对应专家 Agent；同一轮里两类需求并存时，走复合流程并行处理后合并回答。

  • 攻略专家：多轮工具循环（RAG 检索、安全计算等），面向游戏机制与养成问答。
  • 账号专家：只读 MySQL 工具链，按 UID / 关键词查库，避免 LLM 凭空生成表格数据。
  • 闲聊专家：无业务工具，承担寒暄与非任务对话。

03意图路由

默认由 LLM 输出结构化意图（game / account / casual / composite）。 辅以关键词与 UID 启发式纠偏；可通过环境变量切换纯启发式或固定单一路由模式，便于调试与对比实验。

单一意图

命中后直接调用对应专家，保持各 Agent 独立多轮上下文。

composite

拆成攻略子问与账号子问，两路执行后再由编排器合成一段自然语言回复。

04复合问题（并行 + 合并）

拆分失败时可用正则抽取 UID 等规则回退，避免整条链路失败。

sequenceDiagram

  participant G as 攻略 Agent
  participant A as 账号 Agent
  U->>O: 一句话含攻略 + UID
  O->>O: 拆分子问题
  par 并行
    O->>G: game_query
    O->>A: account_query
  end
  G-->>O: game_reply
  A-->>O: account_reply
  O->>O: LLM 合成
  O-->>U: 最终回复

06如何运行

  • CLI：python main.py
  • 网页对话（本页同源）：uvicorn api_app:app --host 0.0.0.0 --port 8000 后访问首页或本展示页
  • Streamlit：streamlit run streamlit_app.py

环境变量需配置 MODEL_NAME、SILICONFLOW_API_KEY；RAG 与 MySQL 详见仓库内 .env.example。
